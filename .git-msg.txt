fix(transport): negotiate the port generation instead of assuming one

Both vendor protocols changed ports once, and both clients hard-coded the old one:
Samsung on `ws://:8001` (2016 era), LG on `ws://:3000` (pre-2023). On a current
panel that is a dead connection, and the "crate does not work" reports follow.

- Tizen tries 8002 → 8001, webOS tries 3001 → 3000, and each client remembers the
  port that answered (`negotiated_port()`), so only the first session pays the probe
  and clones share the answer.
- The fallback is deliberately narrow: `tv_rs_transport::should_try_next_port()` only
  treats *refused / timed out / no route* as "nothing there". A certificate mismatch
  is an answer, not an invitation to retry in plaintext — pinning must never degrade
  silently into no TLS.
- Connection attempts are bounded at 5 s, and the Tizen handshake at 10 s. The frame
  budget caught a silent device only after N frames arrived; a panel that accepts the
  socket and says nothing used to hang the caller.
- `TvClient::from_discovered_with(tv, TlsPolicy)` makes pinning reachable from the
  facade. `from_discovered` keeps `Strict`, so nothing changes for existing callers.
- `TvClient::open_url(url)`: webOS opens it in the built-in browser
  (`ssap://system.launcher/open` — the missing `SsapUri` variant). Tizen returns
  `UnsupportedOperation` because Samsung's URL-launcher is a B2B service that has not
  been verified here, and Roku has no browser. A refusal beats launching an empty
  browser.
- `Debug` is now manual for `TizenClient` and `WebosClient`: the pairing token and
  the `client-key` are bearer credentials and printed as `<redacted>`.

Verification: 4 new tests for the ladder (candidate order, remembered port,
reconfiguration resets it) on both clients, 2 for redaction, 2 for the facade
(policy plumbing, open_url refusals), 2 for `should_try_next_port`; workspace tests
(24 binaries), clippy and rustdoc clean.

Still open from the same review: the shared `reqwest::Client` in the Tizen DIAL path
and the Tizen frame-budget accounting.
